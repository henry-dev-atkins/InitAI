# Merge Checklist

For each worker branch/worktree:

- [ ] Result packet present and complete.
- [ ] Primary Work Type matches the task packet.
- [ ] Changed files are inside declared scope.
- [ ] No temporary diagnostics/fluff/workarounds remain unhandled.
- [ ] Required validation commands passed.
- [ ] `[SPEC.REVIEW]` passed or has only non-blocking findings outside scope.
- [ ] Commit prefix matches repo policy.
- [ ] Branch is merged serially in dependency order.
- [ ] Affected validation re-run after merge.
- [ ] Session board and locks updated.
