# [SESSION.END]

Update docs, `[LEARN]`, `[SESSION.CLEAN]` TODOs, progress and write a detailed handover note for full reproducibility.

Include:

- what changed
- why
- exact commands run
- results
- current state
- work types completed
- agents/workers used, if orchestrated
- checkout state and final commit, if any
- validation status
- open issues and next steps

Open issues are not closure. If open issues are in-scope, mark `[BLOCKED]` unless the human explicitly deferred them.
