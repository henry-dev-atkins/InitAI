# [SESSION.START]

Teach back the project, philosophy, goals and idea.

Then note:

- current spec stage
- recent progress
- last steps
- current blockers
- next steps
- likely work types for today's work
- whether `[TEAM]` / `$orchestrator` is appropriate

Store session work under `$workflow-structure`.

Focus on real capabilities and not software theatre.
