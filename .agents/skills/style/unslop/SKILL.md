# Unslop

Remove writing habits that make text feel generated without removing useful detail.

Preserve the claim, evidence, uncertainty, technical terms, and requested voice.

Use plain words where they carry the same meaning.

Prefer concrete mechanisms, measurements, and actions over mood or praise.

Remove filler openings, generic conclusions, empty transitions, and claims such as "robust" or "powerful" unless evidence supports them.

Remove synonym cycling. Use one name for one concept.

Remove forced rule-of-three phrasing when the source contains a different number of ideas.

Replace "not just X, but Y" with the direct claim.

Prefer active voice when the actor matters.

Split sentences when they contain separate claims or require backtracking.

Do not remove hedges that express confidence.

Do not replace a specific technical term with a vague plain word.

Return the revised text alone unless the user asks for the changes.

When the user asks for changes, show only the useful pattern, the original wording, and the replacement.
