# [CURRENT_STATE]

Summarise only:

- current spec-review result;
- open misalignment IDs;
- active workstreams;
- selected workstreams;
- plan/review status for those workstreams;
- blocked items;
- next loop operation.

This is a cache for resuming work. It is not product authority.
