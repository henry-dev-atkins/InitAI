# [DONE] / [BLOCKED]

For a worker, `[DONE]` means only that the assigned accepted plan completed and was returned for review.

For the orchestrator, `[DONE]` requires a fresh `$spec-review` that returns no material misalignment.

Use `[BLOCKED]` only when required authority, tooling, data, permission, or a safe execution path is unavailable.

Report the exact blocking fact. Do not disguise unfinished implementable work as blocked.
