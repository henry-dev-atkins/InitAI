# Scientific literature review

Use this skill for a focused narrative review, scoping review, or systematic review when the user requests evidence from published work.

Define the question, review type, scope, search cutoff, and eligibility criteria before searching. For technical work, state the task, method, baseline, data, and evaluation measure.

Record the actual sources, dates, queries, filters, records retrieved, records screened, and access failures. Deduplicate records and link preprints, final papers, corrections, and retractions.

Apply the eligibility criteria consistently. Record full-text exclusion reasons. Mark unavailable papers separately from substantive exclusions. Do not call a limited search comprehensive.

Extract the details needed to interpret each included study. Include identity, publication status, setting, sample or dataset, method, comparator, findings, limitations, and the location supporting each important claim.

Separate reported observations, author claims, interpretation, and confidence. Explain conflicting results through observable differences in data, methods, measures, or comparison conditions. Do not treat an absence of located evidence as evidence of absence.

Verify citation metadata against publisher pages, DOI records, or authoritative repositories. A resolving DOI does not prove that a paper supports a claim. Check for corrections and retractions where relevant.

Use systematic-review terms only when the search, screening, extraction, appraisal, and reporting process supports them. Perform meta-analysis only when requested or justified by compatible data and an explicit analysis plan.

Report the question and scope, methods actually used, evidence table, synthesis, limitations, confidence, references, and search record. Use the web tool when current source access is needed. Do not add a local database, search cache, or persistent output directory.
