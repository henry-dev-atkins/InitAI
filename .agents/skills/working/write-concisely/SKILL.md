# Write concisely

Find the main point and place it where the reader needs it.

Remove words that repeat the point or only announce it.

Replace vague nouns with the precise action or object already supported by the source.

Keep the same term for the same concept.

Preserve every condition, exception, qualifier, number, command, path, and identifier.

Keep a longer sentence when shortening it would hide a causal or logical relationship.

Split a sentence when it contains separate actions or claims.

Use active voice when it makes the actor clearer.

Do not strengthen a hedge. "May reduce" must not become "reduces".

Return the revised text alone unless the user asks for an explanation of the edits.
